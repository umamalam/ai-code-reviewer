# AI Code Reviewer

Automated AI code review for GitHub pull requests, with a dashboard for review metrics.

## Live Demo

- **Frontend:** https://ai-code-reviewer-six-xi.vercel.app
- **Backend:** https://ai-code-reviewer-backend-c4zd.onrender.com

Open a pull request on a connected repo and the AI review is posted as a PR comment, with the results showing up in the Dashboard tab.

> Note: the backend runs on a free tier, so the first request after a long idle period may take 30-50 seconds.
